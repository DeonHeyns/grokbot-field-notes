# Task handoff

Copy this into a delegated task or a new conversation. A role name alone is not
a handoff. Do not include unrelated private context.

```text
Task ID:
Owner / role:
Outcome:
Acceptance criteria:
Current artifact and version:
Authoritative sources and dates:
What is already done:
Your assigned subset:
Allowed tools and actions:
Actions that still need authorization:
Output format and destination:
Evidence required:
Deadline / time zone:
Retry limit and stop condition:
Known gaps or conflicts:
Return status: done / partial / blocked, with evidence and next action.
```

For parallel editing, assign disjoint files or configured worktrees. Return
artifacts to the coordinator for integration. If there is no delegation tool,
prepare this handoff or work sequentially; do not claim a worker was launched.
